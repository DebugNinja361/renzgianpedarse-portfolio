# Renz Gian B. Pedarse — Minimalist Portfolio & Resume Website

A modern, minimalist, responsive portfolio website built for **Renz Gian B. Pedarse** showcasing virtual assistant competencies, academic milestones, capstone project leadership, and technical skills.

## ✨ Features
- **Minimalist Aesthetic:** Clean typography, generous whitespace, refined borders, and subtle micro-interactions.
- **Embedded High-Resolution Photo:** Features your official professional portrait in a polished frame.
- **Dark & Light Mode:** Seamless toggle with automatic preference detection and memory persistence.
- **Interactive Actions:**
  - One-click **Copy Email** and **Copy Phone** with instant feedback toast notifications.
  - Direct **Download CV** linking to your PDF resume (`assets/resume.pdf`).
  - **Print Resume** functionality with a dedicated print stylesheet (`@media print`) that formats the page into a clean paper resume when printed or saved as PDF via Ctrl+P.
  - Interactive **Quick Message Form** that opens your default email client with a pre-filled subject and message body.
- **Fully Responsive:** Looks sharp across mobile phones, tablets, laptops, and ultra-wide displays.
- **Zero Dependencies:** Pure HTML5, modern CSS3, and lightweight vanilla JavaScript — runs immediately anywhere without needing Node.js or any build tools.

## 🚀 How to View
Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Mozilla Firefox, or any modern browser.

## 🌐 How to Deploy for Free
1. **GitHub Pages:** Create a repository named `yourusername.github.io`, push these files, and enable GitHub Pages in Settings.
2. **Netlify / Vercel:** Drag and drop the `My Portfolio` folder into Netlify Drop for instant worldwide hosting with a free custom URL.
